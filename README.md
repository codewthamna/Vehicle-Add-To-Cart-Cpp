# Add To Cart System (C++)

## 📌 About the Project
This project is a simple **Add To Cart System** developed in **C++**.  
It allows users to add different types of vehicles to a cart and view all added records using a menu-driven console interface. The project focuses on conditional logic, loops, and basic program flow.

## 🛠️ Technology U
- C++
- Conditional Statements
- Loops
- Console Input/Output

## ✨ Features
- Add **Car** to cart (Option 1)
- Add **Rickshaw** to cart (Option 2)
- Add **Bike** to cart (Option 3)
- View **all added records** (Option 4)
- Handles **invalid input** gracefully

## ⚙️ Process / Working
1. Program displays a menu with available options  
2. User selects an option from the menu  
3. Selected vehicle is added to the cart  
4. User can view all records at any time  
5. Invalid inputs show an error message  
6. Program continues until exit
